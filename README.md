# deneme

Bu repoda telefona kurulabilen (PWA) iki küçük uygulama var:

| Uygulama | Yol | Açıklama |
|---|---|---|
| Borç Takip | `/` | Kredi kartı ve esnek hesap borç takibi |
| 101 Okey | `/101/` | 3 bota karşı oynanan 101 Okey oyunu |

## 101 Okey

- 106 taş (4 renk × 1-13 × 2 + 2 sahte okey), gösterge ve okey kuralı
- Açmak için perlerin toplamı en az **101 puan** olmalı
- Küt (aynı sayı, farklı renk) ve seri (aynı renk, ardışık); 12-13-1 geçerli
- Açtıktan sonra masadaki perlere taş **işleyebilir**, yeni per indirebilirsin
- Elindeki son taşı atan eli kazanır

### Nasıl oynanır

1. Sıra sende iken **desteden çek** ya da solundaki oyuncunun attığı taşı **yerden al**
2. Taşlara dokunarak seç, **Per Yap** ile per hazırla
3. Toplam 101 puana ulaşınca **Aç** ile masaya in
4. Her turun sonunda tek taş seçip **Taş At**

## Telefona kurulum (widget gibi)

Uygulamayı bir web sunucusunda yayınla (örn. GitHub Pages: Settings → Pages → branch seç), sonra telefonda tarayıcıyla aç:

- **Android (Chrome):** ⋮ menü → **Ana ekrana ekle**
- **iPhone (Safari):** Paylaş → **Ana Ekrana Ekle**

Ana ekranda uygulama simgesi olarak açılır, çevrimdışı da çalışır.
